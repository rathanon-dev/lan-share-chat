# 📁 lan-share-chat (LANdrop Lite) 💬

เว็บแอปพลิเคชันสำหรับ**แชทเรียลไทม์ (Realtime Chat)** และ**รับส่งไฟล์ความเร็วสูง (P2P-like File Transfer)** ระหว่างอุปกรณ์ต่าง ๆ ที่เชื่อมต่ออยู่ในเครือข่ายวงแลนเดียวกัน (LAN / Same Wi-Fi) โดยส่งข้อมูลตรงหากันภายในเครือข่าย ไม่ต้องผ่านอินเทอร์เน็ตภายนอก ขับเคลื่อนด้วย Node.js และ WebSockets

---

## ✨ คุณสมบัติเด่น (Features)

- **LAN Share & File Transfer:** รองรับการรับส่งไฟล์ข้ามเครื่อง (คอมพิวเตอร์, มือถือ, แท็บเล็ต) ผ่านการเชื่อมต่อบนวง LAN เดียวกัน
- **Memory-Safe Chunking:** หั่นไฟล์ขนาดใหญ่ออกเป็นชิ้นย่อย ๆ (Chunk ละ 64KB) ส่งผ่านท่อ WebSocket ในรูปแบบตัวเลขอาเรย์ดิบ (Uint8Array) และประกอบร่างกลับด้วย `Blob API` ฝั่งผู้รับ ช่วยประหยัด RAM บราวเซอร์และส่งไฟล์ได้อย่างเสถียร
- **Realtime Group Chat:** ห้องแชทส่วนตัวสำหรับทุกคนที่อยู่ในวงแลน สามารถคุยตอบโต้กันได้ทันทีแบบเรียลไทม์ พร้อมการจำกัดจำนวนตัวอักษรอย่างปลอดภัย
- **Persistent Chat History:** มีระบบบันทึกประวัติการแชทลงฐานข้อมูลภายในตัวเครื่องเซิร์ฟเวอร์ด้วย SQLite3 เปิดปิดแอปใหม่ข้อความไม่หาย
- **Dynamic Peer Discovery:** ค้นหาและแสดงรายชื่ออุปกรณ์อื่น ๆ ที่เปิดใช้งานแอปพลิเคชันนี้อยู่ในวงแลนเดียวกันโดยอัตโนมัติผ่าน IP Address
- **Multi-Tab Alert System:** ระบบแจ้งเตือนผู้ใช้หากมีการเปิดแอปพลิเคชันซ้อนกันหลายแท็บในเครื่องเดียวกัน เพื่อป้องกันสัญญาณทับซ้อนกันขณะรับส่งไฟล์
- **Responsive Design:** หน้าตา UI สวยงาม คลีน สไตล์โมเดิร์น (มีหน้าต่าง Modal ยืนยันการรับส่งไฟล์) รองรับการทำงานเต็มรูปแบบทั้งบนหน้าจอมือถือและเดสก์ท็อป

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend:** Node.js, Express
- **Realtime Communication:** WebSockets (`ws`)
- **Database:** SQLite3 (`better-sqlite3`) สำหรับเก็บข้อมูลประวัติการแชทและชื่ออุปกรณ์
- **Frontend:** HTML5, CSS3 (Vanilla CSS), JavaScript (Vanilla JS) พร้อมระบบคุกกี้ในการจำจดรหัสประจำเครื่อง (`device_id`)

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Installation & Setup)
1. เตรียมความพร้อมก่อนติดตั้ง
* **ทางเลือกที่ 1 (แนะนำสำหรับ Windows):** ใช้เครื่องมือพกพา [portable-dev-env](https://github.com/rathanon-dev/portable-dev-env) ที่เซ็ตระบบ Node.js และ Git ไว้พร้อมใช้งานได้ทันทีโดยไม่ต้องติดตั้งลงเครื่อง (เหมาะสำหรับรันผ่าน Flash Drive)
* **ทางเลือกที่ 2 (แบบทั่วไป):** ตรวจสอบให้แน่ใจว่าเครื่องคอมพิวเตอร์ของคุณมีการติดตั้ง [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน LTS) เรียบร้อยแล้ว

2. ดาวน์โหลดซอร์สโค้ดและติดตั้ง Dependencies เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```Bash
npm install
```
3. เริ่มรันเซิร์ฟเวอร์ สำหรับรันบนสภาพแวดล้อมพัฒนา (Development) ระบบจะใช้ nodemon คอยตรวจจับการเปลี่ยนแปลงของโค้ดให้อัตโนมัติ:

```Bash
npm run dev
```
4. การเข้าใช้งานจากอุปกรณ์อื่นในวง LAN เมื่อเซิร์ฟเวอร์เริ่มทำงานสำเร็จ หน้าจอ Terminal จะคำนวณการ์ดเครือข่ายและแสดง IP วงแลนของเครื่องเซิร์ฟเวอร์ขึ้นมาโดยอัตโนมัติ เช่น:
 
```Plaintext
=====================================================
🚀 เซิร์ฟเวอร์ระบบแลกเปลี่ยนไฟล์และแชทเริ่มทำงานแล้ว!
🔗 [http://192.168.1.35:80](http://192.168.1.35:80)
=====================================================
เครื่องเซิร์ฟเวอร์ (Host): สามารถเข้าใช้งานผ่าน http://localhost หรือ http://127.0.0.1
```
- เครื่องอื่น ๆ ในวงแลน (Client): นำอุปกรณ์มือถือ แท็บเล็ต หรือคอมพิวเตอร์เครื่องอื่นมาเชื่อมต่อ Wi-Fi วงเดียวกัน แล้วเปิดบราวเซอร์วิ่งไปที่ IP ของเซิร์ฟเวอร์ (เช่น http://192.168.1.35) ก็จะเห็นเครื่องของกันและกันและสามารถร่วมแชทกลุ่มหรือส่งไฟล์หากันได้ทันที!

## ⚙️ การตั้งค่าระบบ (Configuration)
นักพัฒนาสามารถปรับแต่งค่าจำกัดความปลอดภัยของแอปพลิเคชันได้ที่ส่วนบนของไฟล์ server.js:
- **MAX_CHAT_LENGTH:** กำหนดจำนวนตัวอักษรสูงสุดต่อ 1 ข้อความแชท (ค่าเริ่มต้น: 500 ตัวอักษร)
- **MAX_NAME_LENGTH:** กำหนดจำนวนตัวอักษรสูงสุดของชื่อเล่นอุปกรณ์ (ค่าเริ่มต้น: 24 ตัวอักษร)
